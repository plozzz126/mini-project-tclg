# Сериальный трекер

Мини-проект № 5. Что смотрю, на какой серии остановился и что выходит сегодня.
Данные — открытая база [TVmaze](https://www.tvmaze.com/api).

- Студент: Пан Роман Сергеевич
- Уровень: **продвинутый**
- Сайт: https://mini-project-tclg.vercel.app/mp5/

## Маршруты

| Адрес | Что там |
|-------|---------|
| `/` | Поиск с задержкой 500 мс (debounce). Карточки: постер или заглушка, название, год, жанры, рейтинг, статус «Выходит / Завершён» |
| `/show/:id` | Сериал, серии и актёры **одним запросом** (`?embed[]=episodes&embed[]=cast`). Описание без тегов. Сезоны раскрываются списком серий с галочками, у сезона прогресс-бар «7 из 13» и кнопка «Отметить весь сезон». Невышедшие серии серые, с датой выхода, отметить их нельзя |
| `/my` | Мои сериалы: «Просмотрено N серий, X ч Y мин», прогресс, кнопка «Следующая серия: S03E05 — название», фильтр «смотрю / закончил / бросил», оценка 1–10, удаление. Блок «Скоро выйдет» с обратным отсчётом, статистика по жанрам и годам, рекомендации, экспорт и импорт JSON |
| `/today` | Что выходит сегодня на стримингах (`/schedule/web`). Мои сериалы показаны отдельно |
| `/people/:id` | Актёр и его сериалы (`/people/:id/castcredits?embed=show`) |
| всё остальное | 404 |

## Устройство

- **`src/api/tvmaze.js`** — `getJson(url)`: кеш в `Map` → запрос → при 429 пауза 2 с и одна повторная попытка. Через неё работают `searchShows`, `getShowFull`, `getTodayWeb`, `getPerson`, `getCastCredits`, `getShowIndex`.
- **`src/lib/episodes.js`** — `stripHtml`, `groupBySeason`, `seasonProgress`, `nextEpisode`, `watchTime`, `isAired`, а также `todayLocal`, `daysUntil`, `countdown`, `upcomingEpisodes`.
- **`src/lib/tracker.js`** — `trackerReducer` (`TOGGLE_EPISODE`, `MARK_SEASON`, `ADD_SHOW`, `REMOVE_SHOW`, `SET_STATUS`, `SET_RATING`, `IMPORT`), `loadTracker` / `saveTracker`, `validateTracker` (проверка формата при импорте), `genreStats`, `yearStats`, `recommend`.
- **Состояние** — `useReducer` в `TrackerContext`, раздаётся через Context и сохраняется в `localStorage`.
- **Тесты** — 24 теста в `src/lib/tracker.test.js`, на файле `src/lib/fixtures/bb.json` (ответ `shows/169?embed…`).

**Что хранится.** На сериал: `name`, `image`, `watched: [id серий]`, а также статус и оценка, которые ставит пользователь.
Дополнительно хранятся `genres` и `premiered`: они нужны для статистики по жанрам и годам без лишних запросов к API.
Названия серий, сезоны и даты всегда берутся из API.

## Проверка (шаг 8)

- **Breaking Bad (id 169):** 5 сезонов, 62 серии.
- **Отметить весь 1-й сезон:** прогресс «7 из 62», следующая серия S02E01 «Seven Thirty-Seven», время 7 ч.
- **F5:** отметки на месте.
- **`abc` в Local Storage:** приложение не падает, трекер пустой.
- **Поиск «breaking bad» при наборе:** уходит 1 запрос, а не по запросу на каждую букву.

## Журнал данных

- **`summary` приходит с HTML:** `<p><b>Breaking Bad</b> follows…`. Текст выводится через `stripHtml`: теги вырезаются, `&amp;` и `&#39;` раскодируются. `dangerouslySetInnerHTML` не используется.
- **Спецвыпуски.** `embed[]=episodes` по умолчанию **не включает** спецвыпуски. У Sherlock (id 335) через `/episodes?specials=1` приходит 18 серий, из них 6 с `number: null`, а через embed — 12. Код всё равно обрабатывает `number = null`: такая серия показывается как «Спец.» и не входит в прогресс.
- **Нет длительности.** В расписании на 2026-11-25 из 94 серий у 36 `runtime: null`. В расчёте времени для таких серий берётся `averageRuntime` сериала.
- **Нет картинок.** `image` у сериала и актёра бывает `null` — тогда рисуется заглушка 📺.
- **Дата и часовой пояс.** Сегодняшняя дата считается по местному времени (`todayLocal`), а не через `toISOString()`: в Алматы до 05:00 UTC-дата ещё «вчерашняя».
- **Повторы у актёров.** У актёра может быть несколько ролей в одном сериале, поэтому сериалы на странице актёра убираются от повторов.

## Как запустить

```bash
npm install
npm run dev     # http://localhost:5173
npm test        # vitest: 24 теста
npm run build
```

Подпись «Данные: TVmaze.com» стоит в подвале. [`vercel.json`](../vercel.json) в корне репозитория переписывает все адреса на `index.html`, поэтому F5 на `/show/169` не даёт 404.
